# INVENTORY

Contains information about the devices in the network, which includes:
- Name of the device
- IP address w/ subnet mask
- Device Model
- Device Location
- Device Status

Changes to device information should be reflected in this file.

# Network Check

Used to check device information and which devices are up. The data is pulled from the inventory and stored in the output file.

# Output

History of the changes made to the devices is stored here, with each entry containing an ID, the time changes were recorded, and the configuration of the devices at the time.
